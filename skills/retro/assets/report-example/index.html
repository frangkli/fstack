How to use this composition

Keep the underlying report in its owning project's retros/ directory under that repository's private-docs conventions. Replace all illustrative material. Adapt the scorecard and charts to the flow, audit every coverage dimension, and retain unknowns. Existing exports and small calculations are sufficient.

This public, generic example contains no project sessions or private evidence. It is a skill asset, not a retrospective record. No decision is requested.
